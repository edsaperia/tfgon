# The old site, kept for reference

The coordinator saved these on 2026-11-27 from https://www.techforgoodorganisers.uk/, the inherited Webflow site whose login has been lost. Pointing the domain at the new site turns the old one off, and its Webflow files may disappear whenever its plan lapses.

- `TFGON_Logo_Colour.svg`, `TFGON_Logo_White.svg`: the logo, a mark of four overlapping strokes plus the words "Tech for Good / Organisers' Network". The words are drawn as shapes, so no font is needed.
- `tfgon-icon-clear.svg`, `tfgon-favicon.png`: the mark on its own, and the old browser-tab icon.
- Logo colours: pink `#EF476F`, yellow `#FFD166`, green `#06D6A0`, blue `#118AB2`, and the dark grey `#393E46` used for the words.
- `homepage-text.md`: the old homepage's words.

Nothing in this folder is published. Pages publishes only `/docs`.
